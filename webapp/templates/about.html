About Rap Bot

Rap Bot is an evolutionary rap verse generation system. It uses quality-diversity (MAP-Elites) and other evolution strategies to generate verses that match rhyme schemes, themes, and stylistic goals.

Quick start

Open the Dashboard to see runs. To log new runs here, enable the database and use --db --runs-dir when starting a run.

Full example (QD verse evolution, 100 pop, 60 gens, DB logging): 

python scripts/run_verse_qd.py --theme "pressure,mask,survival" --population 100 --generations 60 --scheme ABAB --init lm --db --runs-dir

Logging runs to the dashboard

To see evolution runs in this dashboard, enable database logging and use --db and --runs-dir when starting a run.

  • Set RAPBOT_USE_DB=1 in your environment (or in .env).
  • Configure DB connection: RAPBOT_DB_HOST, RAPBOT_DB_PORT, RAPBOT_DB_USER, RAPBOT_DB_PASSWORD, RAPBOT_DB_NAME (default: rapbot).

Example: QD verse evolution

python scripts/run_verse_qd.py --theme "pressure,flow,mask" --population 100 --generations 80 --scheme AABB --init mixed --db --runs-dir

Example: verse evolution (non-QD)

python scripts/run_verse_evolution.py --theme "pressure,mask,survival" --population 80 --generations 30 --scheme AABB --runs-dir
